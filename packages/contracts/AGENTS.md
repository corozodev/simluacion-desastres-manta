# Contrato HTTP

`openapi.yaml` es la fuente de verdad. Modifica primero el contrato y ejecuta `npm run contracts:validate` y `npm run contracts:generate` desde la raíz. No edites `generated/` manualmente. Conserva la versión OpenAPI 3.0.3, los nombres de los esquemas compartidos y el sobre común de errores. Documenta cambios visibles y mantén ejemplos válidos.
